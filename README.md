# dv_qmd Quarto Extension

A lightweight Quarto extension I created for personal use, providing Typst templates and APA-style citation formatting. Maintenance and updates are minimal.

![Quarto Extension](https://img.shields.io/badge/quarto-extension-blue)
[![License: MIT](https://img.shields.io/badge/license-MIT-yellow.svg)](LICENSE)

---

## Features

- Typst template for PDF output
- APA-style citation formatting (not a full APA template)
- Planned DOCX and HTML templates
- Optional use of the Lato font

## Prerequisites

- Quarto CLI (version 1.x or higher)
- (Optional) Lato font — install from [Google Fonts](https://fonts.google.com/specimen/Lato)

## Installation

```bash
quarto use template donvollb/dv_qmd
```

or

```bash
quarto add donvollb/dv_qmd
```
